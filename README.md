# 💩 Operação: Salvem o Tiago!

**30 segundos. Uma sanita. Uma vida em jogo.**

Jogo 2D de corrida para telemóvel (HTML5 + Canvas + Web Audio), num único ficheiro, sem dependências e sem servidor.

## Jogar
Abre o link do jogo no telemóvel e **roda-o para a horizontal**.

- Botão verde: **SALTAR**
- Botão vermelho: **DESLIZAR** (mantém carregado)
- Teclado (testes): ↑ / Espaço = saltar, ↓ = deslizar, P = pausa

Vence o jogo, desbloqueia o **Modo Intestino de Aço**.

## Alojar (GitHub Pages)
1. Carrega `index.html` para um repositório público.
2. Settings → Pages → Branch `main` → Save.
3. Link: `https://TEU-NOME.github.io/NOME-DO-REPO`

## Testes
A lógica do jogo está separada do ecrã e foi simulada em Node: a vitória perfeita acontece aos 29,000 s (cronómetro 00:01) sem colisões, nos dois modos.
